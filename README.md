# EverAfter — Wedding Management System

A premium client-side B.Sc. Computer Science academic project based on the supplied project brief.

## Technology
- HTML5
- CSS3
- Vanilla JavaScript
- localStorage for demo authentication and bookings

## Main Modules
Home, Wedding Services, Venue Management, Package Selection, Booking & Guest Management, Dynamic Cost Calculation, Contact.

## Run
Extract the ZIP and open `index.html` in a modern browser. No server or installation is required.

## Demo Authentication
Create an account from Sign Up. Credentials are stored in browser localStorage for demonstration only.

## Cost Formula
Total Cost = Venue Price + Package Price + (Number of Guests × ₹500) + Additional Services

## Important limitation
This is a client-side academic demonstration. It does not process real payments and does not provide production-grade authentication. A future version can connect User, Booking, Venue and Package entities to a server-side database.

## Features
- Login / signup / logout
- Protected dashboard and booking flow
- Multi-step booking
- Venue search and sorting
- Package selection
- Service selection
- Live budget calculator
- Booking history
- Countdown
- Responsive premium UI
- Toasts, modals, loading screen and animations
- Printable booking confirmation
